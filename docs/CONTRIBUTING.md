# Contributing

## About the project

GrammPlayer is an Android app written in Java using Telegram's official TDLib.
This website lives in a separate repo and is plain HTML with no build step.

## Reporting bugs

Open an issue at https://github.com/abinsabu2/GrammPlayer/issues/new with steps
to reproduce, expected vs. actual behavior, and device/OS details.

## Submitting changes

- For the app: fork https://github.com/abinsabu2/GrammPlayer, create a branch,
  and open a pull request against that repo.
- For this website: fork this repo, create a branch, and open a pull request
  here. Before submitting, run:

```
python3 test_html_checks.py
python3 test_store_links.py
```
